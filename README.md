# Branche gh-pages : redirection

Le site a déménagé sur https://truffe.topo-host.com. GitHub Pages publie cette branche, qui ne
contient que des pages de redirection : chaque ancienne adresse
`tompoyeau.github.io/truffe-gourmande/<page>` renvoie vers la même page à la nouvelle adresse.

Le code du site reste sur la branche `main`.
